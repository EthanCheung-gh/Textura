# 周报 / 月报 / 季报：视觉与交互走查清单

执行者：1 名熟悉本项目的开发或 QA，在装了 Node 22+、Chrome 稳定版与 Rust/Tauri 工具链的本机上，按「浏览器模式 + Tauri 桌面模式」双环境逐条执行；预计 90–120 分钟（第 7 组需要可用的大模型网关，另加 20 分钟）。

## 怎么用这份清单

- 每条都是「操作 → 预期 → 失败判定」三段式，逐条判定，只有三种结论：通过 / 失败 / 阻塞。
- 标 `（可脚本化）` 的条目可以用 DevTools 控制台或 `scripts/qa/` 下的 CDP 脚本自动断言，其余靠肉眼。
- 先读这一段模式差异，再开始执行：复制 Markdown 在浏览器与桌面模式都可用；下载 `.md` 在浏览器可靠落文件，在 Tauri 桌面模式可能完全没有反应（已知边界）；工作区导入 / 导出在 Tauri 走系统文件对话框，在浏览器走下载与文件选择框。
- 执行中不要改代码、不要改配置默认值、不要 git 提交；发现失败按第 12 组的方式记录。

## 1. 环境与数据准备

- [ ] ENV-01 运行 `npm --prefix ../textura-mcp install && npm --prefix ../textura-mcp run build`（仅首次；`predev` / `prebuild` / `pretest` 也会自动跑 build）→ 预期：`../textura-mcp/dist` 生成、`@textura/mcp` 可解析 → 失败判定：`npm run dev` 报找不到 `@textura/mcp` 模块。
- [ ] ENV-02 运行 `npm run dev`，打开 `http://localhost:1420/?route=reports` → 预期：端口固定 1420，直接进入周报页 → 失败判定：端口被占用直接退出，或深链落到今日页。
- [ ] ENV-03 运行 `npm run tauri dev` → 预期：1440×900 桌面窗口载入同一页面，读写同一份工作区数据 → 失败判定：窗口白屏，或 devUrl 连到错误端口。
- [ ] ENV-04 在设置页点「重置为演示数据」并确认「覆盖并重置」→ 预期：演示数据生效（含收件箱条目与 SOP 运行记录），可用 Ctrl+Z 整次回退 → 失败判定：没有二次确认，或重置后周报页报错。
- [ ] ENV-05 在设置页「导出 JSON」，删掉文件里的 `reports` 键，另存 `old-workspace.json` → 预期：文件仍是合法 JSON 且不含 `reports`；Tauri 模式记得确认系统文件对话框的保存路径 → 失败判定：导出无反应，或改文件时误动原工作区。
- [ ] ENV-06 从导出文件复制一份，改成「脏数据」另存 `dirty-workspace.json`：`period` 写 `"下周"`、`sections` 放 41 节、单节 `body` 放 200k+ 字符、某节 `origin` 写 `"robot"` → 预期：两份样本就位，供第 9 组使用 → 失败判定：样本未生成，或修改落在真实工作区文件上。

## 10. 已知不可自动化 / 本轮明确不验

以下六项本轮不作为判定项，只需要在记录表里备注一句「不验」，不给通过结论：

- 真实网关的 CORS 白名单策略：依赖外部服务配置，本轮只用「不允许直连的网关」验证文案分支。
- 剪贴板权限的跨浏览器差异：只在 Chrome 稳定版验证「复制 Markdown」，其他浏览器与桌面 webview 的权限弹窗不展开。
- 像素级视觉对比：本轮只做「不裁切、不重叠、不撑破」的结构性判断，不做基线截图 diff。
- 跨平台字体与行高差异：只在当前执行机器上验证，Windows / Linux 的字体回退差异不在本轮范围。
- 移动端窄屏（< 768px）：产品非目标场景，本轮最低只到 1024×720。
- Tauri 桌面模式下的 AI 直连：桌面 webview 的内容安全策略未放行外网 https 出口，AI 请求预期被拦截；第 7 组全部在浏览器模式执行，桌面模式只验证「拦截后提示的是网络类错误、不崩」。
     存疑：这是实现层面的现状而非偶然现象，若要桌面端可用需放开 connect-src 或改走宿主代理，本轮不改代码，仅记录。（待确认）

## 12. 失败处理约定

- 每条失败在记录表「实际」列写一句客观现象，再补一段最小复现，落到 `实际` 列下方或独立的备注区，不要另建散落文件。
- 最小复现必须包含：操作步骤、视口尺寸与缩放比例、主题（浅色 / 深色）、模式（浏览器 / Tauri 桌面）、浏览器或 Tauri 版本、系统版本、数据来源（演示数据 / 导入文件 / 手工造数）。
- 附一张截图（命名见第 11 组），涉及报错时再粘 Console 原文；粘之前确认里面没有 `sk-` 开头的密钥片段。
- 同一现象在多条编号下出现时只记一条失败，其余条目标注「同上，见 <编号>」，避免同一问题被重复计数。
- 判定为失败的条目**不要就地改代码、不要临时改配置绕过**；需要修复时另开任务，本轮只留证据。
